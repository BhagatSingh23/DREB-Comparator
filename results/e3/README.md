# Experiment E3: DREB v2 Ablation & Parameter Sweeps

## 1. Overview and Protocol
Experiment E3 tests the contributions of DREB v2's adaptive terms and optimizes parameters.
- **Tuning Phase (Seeds 1000–1029):** Swept `sustainedCostGain`, `abuseIncrement`, `abuseDecayRate`, and `abuseGain`.
- **Selection Rule:** Maximize abuser rejection rate subject to legit $\text{FRR}_{\text{overall}} \le \text{FRR}_{\text{TB-large}} + 0.1\text{ percentage points}$.
- **Winning Tuning Setting:** `sweep abuseDecay=0.25`
- **Held-Out Test Phase (Seeds 2000–2029):** Independent evaluation of baselines, ablations, and the chosen configuration.
